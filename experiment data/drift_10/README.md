# SalesX 10% quarterly-drift variant

This is the nominal SalesX benchmark. Q2, Q3, and Q4 each contain 50
changed-answer tickets (10%), produced by two changed articles in each of the
five categories.

Q1 and the optional post-Q4 Extra abstention split are canonical shared inputs
stored in `../shared`. The manifest references those files directly, so the
10% and 40% variants cannot diverge during the CEO bootstrap.
